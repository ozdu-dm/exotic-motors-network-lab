# Imágenes de vehículos

Las imágenes de los vehículos no se distribuyen con el repositorio.

Para ejecutar la webapp localmente, coloca en esta carpeta los archivos JPG
con los nombres que aparecen en la columna `img` de la tabla `coches` del schema SQL.

Ejemplo de nombre esperado: `ferrari_sf90_stradale.jpg`

Las imágenes se sirven directamente por Nginx en producción desde `/var/www/exoticsweb/static/img/`.
